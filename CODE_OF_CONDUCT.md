# Code of Conduct

## Our commitment

We want this repository to be welcoming, focused, and respectful for everyone who participates in issues, pull requests, and review discussions.

## Expected behavior

Please:

- be respectful and constructive
- assume good intent while discussing ideas
- focus feedback on the work, not the person
- keep discussions relevant to the repository scope

## Unacceptable behavior

Please do not engage in:

- harassment, threats, or hateful conduct
- personal attacks, intimidation, or doxxing
- deliberately disruptive or bad-faith behavior
- spam or repeated off-topic promotion

## Scope

This code of conduct applies to public interactions in this repository.

It does not change the repository authority model. Root `AGENTS.md` remains the only repo-governance authority in `unified-framework-kit`.

## Reporting

If you experience or witness unacceptable behavior, please contact the repository owner privately through GitHub when possible. For general moderation questions that are not sensitive, you may use the issue tracker.

## Enforcement

Repository maintainers may remove, edit, or reject comments, issues, pull requests, and other contributions that violate this code of conduct.
