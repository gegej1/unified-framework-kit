# Examples

Examples are intentionally deferred in the initial public release.

## Current status

- Batch 1 ships this placeholder only
- No formal example project is included yet
- Examples are **not** an authority surface

## Why examples are deferred

The initial release prioritizes a clean authority model and a readable minimum-kernel surface. Shipping examples too early would risk making examples look like the main contract.

## Planned direction

Formal examples are expected in a later batch and should start as **minimal readable skeletons**, not as the primary source of truth for the framework.

Until then, start with the architecture, reference, and guide documents.
