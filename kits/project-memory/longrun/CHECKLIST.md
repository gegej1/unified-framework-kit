# longrun Session Checklist

This page is kept in Batch 2 Wave 1 as a **compatibility shim**.

- It remains a public-facing checklist entry point for the Project Memory Layer.
- It is **not** the repo-governance authority of `unified-framework-kit`.
- It is **not** the future home of the formal seed set.
- The real seed surface is planned to converge under `kits/project-memory/longrun/seed/` in a later wave.

## Start of session

- Confirm the active project path and rules layer
- Read the current project bearings and long-term facts
- Re-check any migration constraints that still matter
- Re-open the current feature or work target
- Re-verify at least one already-known passing behavior when appropriate

## During session

- Work on one clear unblocked target at a time
- Test through the relevant user flow or verification path
- Capture concrete verification evidence
- Treat regressions as first-class issues

## End of session

- Update only the durable fields that the evidence supports
- Record what changed, what remains blocked, and what should happen next
- Confirm no layer boundary was violated during the session
- Ensure no known critical breakage remains before handoff

## Boundary reminder

- Project Memory is not Feature Delivery
- Project Memory is not runtime execution behavior
- Durable completion still requires evidence-backed traceability
- This shim should not grow into a new authority surface during the transition to the future `seed/` layout
